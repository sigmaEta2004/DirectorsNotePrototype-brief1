# DirectorsNotePrototype-brief1

A prototype film discovery explorer for **Directors Notes** (Brief 1: Film Discovery Explorer), built for the Creative Process Development Bootcamp.

## Context & Opportunity
Directors Notes currently runs on an outdated WordPress template with an unreliable search function. This prototype explores a cleaner, custom search experience—allowing visitors to find short films using plain-text descriptions, filmmaker names, or keyword/tag matching when they don't know the exact title.

## Intended Visitor
Users who are new to short films or are trying to track down a specific short film without knowing its name.

## Starting Point
Build a working home page that displays film cards, laying the groundwork for basic and advanced keyword search features.

## Asset Approach
This prototype begins with an HTML and CSS visual treatment. No Directors Notes photographs, film stills, videos, logos, or client archive data are used in this repository.
